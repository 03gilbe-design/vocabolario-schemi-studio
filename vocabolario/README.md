# Vocabolario

Le regole per fare uno schema di studio nel mio stile. **Per usarle in chat ti basta [`pronto_per_il_modello/PACCHETTO_MODELLO.md`](pronto_per_il_modello/PACCHETTO_MODELLO.md)** (tutto in un file); gli altri file sono le parti spiegate una per una.

| File | Cosa c'è |
|---|---|
| [pronto_per_il_modello/](pronto_per_il_modello/) | `PACCHETTO_MODELLO.md` = tutto in un file da allegare in chat; `regole/` = una regola per file (14) con il ritaglio d'esempio |
| [A_VOCABOLARIO.md](A_VOCABOLARIO.md) | le 14 regole generali (5 gruppi), con gli esempi in fondo |
| [B_NON_FARE.md](B_NON_FARE.md) | cosa il modello NON deve fare (legende, passi 1-2-3, cruscotti...) |
| [C_STILE.md](C_STILE.md) | il tono dei miei schemi: palette, font, pattern |
| [D_MODULO_ESTRAI_REGOLE.md](D_MODULO_ESTRAI_REGOLE.md) | i prompt per estrarre una regola nuova da una coppia pagina del prof → mio schema |
| [E_AGGIUNTA_FIGURA.md](E_AGGIUNTA_FIGURA.md) | una frase in più se le pagine escono a pezzi staccati |
| [PACCHETTO.md](PACCHETTO.md) · [PACCHETTO.pdf](PACCHETTO.pdf) | cosa dare al modello e in che ordine, con quanti token pesa ogni parte |
